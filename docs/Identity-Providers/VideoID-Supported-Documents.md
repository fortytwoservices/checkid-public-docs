# VideoID Supported Documents

Signicat VideoID is one of the identity providers available in CheckID. The table below lists, per issuing country, the identity documents accepted when a user verifies with VideoID.

**Note:** Passports are not supported. Most passports don't include a national identity number, which CheckID needs to verify the user.
