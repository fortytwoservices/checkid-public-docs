# Supported Languages and Locales

CheckID currently supports the following languages and browser locales:

| Language | Browser locales |
| -- | -- |
| English | `en`, `en-GB` |
| Norwegian Bokmål | `nb`, `nb-NO` |
| Finnish | `fi`, `fi-FI` |
| Swedish | `sv`, `sv-SE` |
| Danish | `da`, `da-DK` |
| Polish | `pl`, `pl-PL` |

## Default Language

The default language can be set to any of the supported languages. If a user's browser locale is not supported, CheckID displays the service in the configured default language.

For example, if the default language is English and a user's browser locale is `de-DE` (German), CheckID displays the service in English.

## Requesting a New Language or Locale

If you would like CheckID to support another language or locale, please contact us.
